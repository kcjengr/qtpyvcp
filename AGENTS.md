# QtPyVCP — Agent Instructions

## Setup & Commands

**Install (Poetry):** `poetry install`
**Run app:** `poetry run qtpyvcp`
**Run example VCP:** `poetry run mini` or `poetry run brender`
**Run tool:** `poetry run <script-name>` (see `[tool.poetry.scripts]` in pyproject.toml)
**Fallback install:** `pip install -r requirements.txt && pip install -e .`

**Build docs:** `make -C docs html`

## Architecture

- **src/ layout**, 3 packages: `qtpyvcp`, `examples`, `video_tests` (declared in pyproject.toml `packages`)
- **`qtpyvcp.app:main`** — application bootstrap entrypoint
- **`qtpyvcp.plugins/`** — plugin system with entrypoints registered under `[tool.poetry.plugins]` in pyproject.toml (e.g. `qtpyvcp.example_vcp`, `qtpyvcp.test_vcp`)
- **`qtpyvcp.tools/`** — CLI utilities, each exposes `main()` and is registered as a console script in pyproject.toml
- **`qtpyvcp.widgets/`** — widget library (HAL-connected, display, input, dialog, container types)
- **`linuxcnc/configs/`** — LinuxCNC config examples (`sim.qtpyvcp`, `sim.qtpyvcp.foam`, `sim.qtpyvcp.machine_parts`)

## Gotchas

- **No pytest suite.** Verification is manual via example VCPs (`src/examples/`) and `video_tests/`.
- **`.ui` files are source artifacts.** Edits to `.ui` files should be verified by running the example that uses them. Preserve relative resource paths.
- **Versioning:** auto-generated by `poetry-dynamic-versioning` + git tags via versioneer. Never hand-edit `_version.py` or the `version` field in pyproject.toml.
- **Qt bindings:** supports PyQt5 or PySide2 (Qt 5.15 targeted). Code uses QtPy abstractions — don't import from a specific binding directly.
- **LinuxCNC is a runtime dependency.** The app expects to run inside or alongside LinuxCNC with HAL available.
- **New console scripts:** add to `[tool.poetry.scripts]` in pyproject.toml. New plugins: add to the appropriate `[tool.poetry.plugins."..."]` section.
